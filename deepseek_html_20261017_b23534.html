Empat langkah. Selesai.

Dari nol ke bot aktif dalam hitungan menit.

1

Setup Termux

pkg install nodejs git tmux. Verifikasi dengan node -v. Node 18+ wajib.

2

Instal Bot

npm i @whiskeysockets/baileys qrcode-terminal pino. Jalankan node bot.js. Scan QR.

3

Push GitHub

git init, commit, remote add. .gitignore: auth_info/, node_modules/. Push ke main.

4

Aktifkan Pages

Settings → Pages → branch main → root. Landing live di USERNAME.github.io/repo.
